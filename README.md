# Projeto Calculadora POO

## Objetivo
Desenvolver uma calculadora utilizando os principais conceitos de Programação Orientada a Objetos.

## Conceitos Aplicados

### Herança
As operações matemáticas herdam da classe abstrata Operacao.

### Polimorfismo
Cada operação implementa seu próprio método de cálculo.

### Composição
A classe Calculadora possui internamente um objeto Histórico.

### Associação
A classe Usuário utiliza a Calculadora.

### Agregação
A Calculadora pode utilizar um formatador de resultados externo.
